# core - react

## 🚀 Cómo correr el proyecto


1. Instala las dependencias:
```bash
   npm install
```

2. Crea tu archivo de variables de entorno copiando el ejemplo:
```bash
   cp .env.example .env
```
   > En Windows (PowerShell): `copy .env.example .env`

3. Corre el proyecto:
```bash
   npm run dev
```
